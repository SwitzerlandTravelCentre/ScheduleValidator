# Security

## Supported Versions

The current `main` branch is the supported version.

## Reporting a Vulnerability

Please report security concerns through the repository's private security
advisory flow or the Switzerland Travel Centre internal security channel.

Do not open a public issue for vulnerabilities.

## Data Handling

The app stores trip configuration only in the user's browser via `localStorage`.
It does not send package, location, or event data to a server.

Do not commit real customer data, supplier contract data, booking references, or
personal information to this repository.
