# Design Direction

This app follows the provided Airbnb-inspired reference as a practical UI
direction for the FIT Package Validator.

## Core Tokens

- Canvas: `#ffffff`
- Ink: `#222222`
- Body text: `#3f3f3f`
- Muted text: `#6a6a6a`
- Hairline: `#dddddd`
- Soft surface: `#f7f7f7`
- Primary accent, Rausch: `#ff385c`
- Primary active: `#e00b41`

## Principles

- Use a mostly white interface with one primary accent.
- Keep surfaces flat; use one subtle shadow only for hover or important floated
  controls.
- Prefer rounded controls: 8px buttons, 14px panels, fully rounded pills where
  a control behaves like a search/filter surface.
- Keep type modest: quiet headings, 400-600 body weights, strong numbers only
  where they summarize status.
- Make the calendar the visual anchor and keep supporting controls compact.
- Use event badges sparingly and reserve strong color for blocked start dates
  and primary actions.
